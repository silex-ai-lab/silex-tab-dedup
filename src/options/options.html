Which URLs count as the same page

Leave off for apps such as Gmail that use the fragment to tell pages apart.

Never treat as duplicates

One pattern per line.

  • mail.google.com a domain and its subdomains
  • github.com/*/pull/* * matches anything
  • /^https:\/\/x\.com\// a regular expression between slashes

Advanced matching

Treat as one page

Every URL matching the same line counts as the same page. Same pattern syntax as above.

Sites with several domains

One domain pattern per line, such as yandex.* (yandex.ru = yandex.com). Pages still need the same path.

Applies to the badge, the popup list and the shortcut, not to automatic closing.
